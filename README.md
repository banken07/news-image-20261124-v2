# news-image-20261124 v2 — "Sum up 24 November's world news in one image"

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/news-image-20261124)

One 1024x1024 PNG summing up Tuesday 24 November 2026 world news:
26 stories across 7 regions, all first reported on Tuesday, with a UTC
timeline, a 6-number stat strip, a numbered world map, and a DATE CHECK
box listing what was left out (and why).

Run: `MAKEFUN_OUTPUT_DIR=/output python3 main.py` (pure Python 3 stdlib;
glyphs.json holds the embedded Liberation Serif outlines).
